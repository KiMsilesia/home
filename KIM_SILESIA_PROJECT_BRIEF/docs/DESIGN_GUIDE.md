# KIM SILESIA — DESIGN GUIDE

## Charakter
Nowoczesny premium. Architektoniczny, spokojny, profesjonalny.

## Kolory
Priorytet:
- granat KIM SILESIA,
- biel,
- jasne neutralne szarości,
- grafit / antracyt jako uzupełnienie.

Akcent ciepły można stosować bardzo oszczędnie.

## Typografia
Preferowane:
- duże, zdecydowane nagłówki,
- czytelny sans-serif dla treści,
- krótkie linie tekstu,
- dużo światła / whitespace.

## Kompozycja
- szerokie sekcje,
- duże zdjęcia,
- wyraźna hierarchia,
- maks. 1–2 główne CTA w sekcji,
- nie przeładowywać kartami.

## Logo
Używać pliku:
`../references/branding/logo-kim-silesia-approved.png`

Nie przerysowywać i nie generować na nowo.

## Mieszkaj w Mieście
Dedykowana strona powinna prowadzić klienta:
1. rozpoznanie osiedla,
2. obietnica kompleksowego wnętrza,
3. trzy standardy,
4. konkretne różnice,
5. realizacje / wizualizacje,
6. kontakt / prezentacja.

## Standard / Plus / Premium
PLUS może być wizualnie wyróżniony jako wariant rekomendowany / najlepszy balans, ale bez agresywnej sprzedaży.
