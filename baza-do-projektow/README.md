# Baza do projektów — materiały źródłowe

Tu przechowujemy **oryginalne pliki** do ponownego montażu rolek i innych projektów 3D SILESIA.

## Proponowany porządek

- `rolka-1/` — oryginalne rendery, logo, muzyka i inne źródła do pierwszej zaakceptowanej rolki.
- `rolka-2/` — materiały do drugiej zaakceptowanej rolki.

Foldery pojawią się na GitHubie po dodaniu do nich pierwszego pliku. Nie nadpisuj oryginałów — kolejne wersje filmów publikujemy osobno.

**Uwaga:** GitHub nie jest najlepszym miejscem do przechowywania bardzo dużych plików. Pojedynczy plik przesyłany przez stronę GitHub ma limit 25 MiB. Przy większych materiałach lepiej wykorzystać Git LFS lub zewnętrzny magazyn plików.
